# 审批画布折叠组

## 范围

仅改变 PC 设计器展示，不改变模型、审批权限、节点条件、执行顺序或发布版本。

- 同一序列中连续三个及以上含 FORM_USERS 选人规则的审批节点，默认汇总为“动态审批组”。不依赖业务名称、部门编号、模型 key；识别阈值由纯函数参数控制。
- 顺序节点摘要明确显示“依次审批”，不宣称后台已支持部门并行。跨分支边界不合并。
- 已有条件、并行、顺序和子流程分支可手动折叠，显示真实分支类型和数量。
- 展开后使用原节点引用及原数组索引，原有配置、插入、删除入口保留。只读流程允许折叠，但仍禁止编辑。
- 折叠状态仅存在组件内存，不写入 Definition 或设计草稿，不触发 changed，不覆盖业务规则。

## 扩展方式

`designer/presentation.ts` 是展示投影层，独立于 `graph.ts` 的保存和执行转换。后续新增分组识别策略应在投影层增加，并测试空列表、短序列、分支边界、原索引及原始模型不变；不要通过添加虚构执行节点实现折叠。
