- PC：`/operation/inspection-preview`，组件 `operation/inspection/index`。已登录且用户名精确为 `admin` 才显示数据和允许操作。
- 入口为「运维管理 → 巡检管理」独立PC子菜单，后台已创建并仅授予admin角色；管理员已从侧栏实测打开。路径不变，隐藏路由/隐藏Tab关闭、缓存关闭。移除值班表临时入口及全局静态预览路由，由后端授权菜单加载；不修改审批配置及值班表现有接口。现阶段组件仍保留admin账号Mock门禁。
- 四层采用页内 Tab：巡检对象、巡检点、巡检任务、巡检记录；配置编辑进入同路由的完整编辑区域。页面沿用 OA 与 BasicTable，包含搜索、分页、公共列设置。
- 本轮仅 PC Mock；移动端工程未修改。客户、巡检人均为虚拟演示选项，不查询真实名单。

## 数据与操作

- `inspection.mock.ts`：类型、种子、校验、生成、提交、办结规则；`index.vue`：列表、配置表单、执行及附件本地预览、Excel 导出。
- 数据键：`shkj:inspection:mock:v1:admin`。仅本浏览器保存，刷新保留；无痕窗口关闭后可能清除，不支持跨设备、跨用户或多人同步。不触碰真实业务数据。
- 对象：名称、唯一编号、启停、备注、检查项，新增/编辑/复制/删除、检查项排序。被引用的检查项不能删除；被引用的对象不能删除，可停用。
- 巡检点：通用/客户定制、名称编号、备注、按对象选择检查项。移除关联不删除对象公共定义。被任务引用的巡检点不可删除。
- 任务：演示客户、演示巡检人、有效期、每月次数、巡检点与巡检单数量。保存与生成分开；已生成记录的任务不能删除。修改配置不回写已有记录。
- 生成规则仅为演示假设：自然月，每月1～12次，各次共享当月执行窗口；首尾月裁切有效期。每个巡检点1～20张单；有效期不超过24个月，总生成量最多1000张。按任务ID+月份+轮次幂等生成。三套智能闸口每次生成三张单，位置编号可在执行时修改。
- 每张执行单冻结对象名称、检查内容；填写正常/异常、位置、结论及附件，变化本地保存；全部检查项和结论完整才允许提交。提交后只读。执行进度按已提交巡检单/总巡检单计算。
- 执行状态、巡检结果、异常处理分离；已完成可同时异常待处理。异常提交后填写办结说明并二次确认，本地记录办理人和时间，保留原异常结果。无真实审批或维修工单联动。
- 现场与办结图片/视频分别最多3个，单个2MB以内；FileReader读取本地，不上传；空间不足明确提示未持久化。Excel导出明细文字，带Mock标记，不嵌入附件。
