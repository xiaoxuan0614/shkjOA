# 项目创建 字典配置说明

> 更新：2026-08-18
> 对应代码：`src/views/project/Project.data.ts`、`src/views/project/apply/ProjectApply.vue`
> 📌 全模块字典清单（含合同/外协/回款/实施/方案等）见 [字典配置说明](../字典配置说明.md)

## 一、字典编码清单（系统管理 → 数据字典 配置）

| 字典编码 | 含义 | 单选/多选 | 使用位置 |
| --- | --- | --- | --- |
| `project_type` | 项目类型 | 单选 | 新增/编辑项目表单「项目类型」；项目管理/计划方案管理 搜索「项目类型」 |
| `project_business_attr` | 业务属性 | 多选 | 新增/编辑项目表单「业务属性」 |
| `project_products` | 涉及产品清单 | 多选 | 新增/编辑项目表单「涉及产品清单」 |
| `project_period_status` | 项目分期状态 | 单选 | 项目管理/计划方案管理 列表「项目状态」标签、详情头部状态徽标、搜索「状态」 |
| `contract_type` | 合同类型 | 单选 | 合同签订/审批弹窗「合同类型」（项目合同/维保合同/无合同） |
| `contract_status` | 合同状态 | 单选 | 项目管理列表「合同状态」列、合同弹窗（0驳回/1待审批/2已通过） |

前端逻辑：上述下拉一律通过 `ApiSelect` + `initDictOptions(code)` 从字典加载；**无硬编码兜底**（字典未配置则下拉为空，需后台建字典）。

## 二、字典项 value 一致性（重要）

- **项目类型 / 业务属性 / 涉及产品：真实后端存的是编码**（如 `1`、`2`），业务属性/涉及产品为**逗号分隔字符串**（如 `"2,1"`）。
- 因此字典 `value` 用编码（`1/2/3...`），`text` 为展示文案；多选字段前端自动做「数组 ⇄ 逗号字符串」转换：
  - 编辑回显（`ProjectApply.vue loadDetail`）：`"2,1"` → `["2","1"]`
  - 保存提交（`handleSave`）：`["2","1"]` → `"2,1"`
- `project_period_status` 的 `value` 为状态码（`NOT_STARTED/IMPLEMENTING/...`），与后端 `period.status` 一致。
- `contract_status` 的 `value` 为 `0/1/2`；`contract_type` 建议 value 用中文文本（项目合同/维保合同/无合同）。

## 三、多选提交格式

业务属性 / 涉及产品清单前端收集为数组，保存时 `join(',')` 提交为逗号分隔字符串（对齐后端存储）。

## 四、项目地址（地图选点，带锁定交互）

- 项目地址（新增/编辑项目表单）为**内联地图选点**：输入框下方直接显示高德地图 + 红色定位 pin。
- **默认锁定**：地图不可拖动/搜索，只显示当前 pin；点击「修改定位」才解锁，拖动/搜索调整后点「保存」回写地址+经纬度，或「取消」还原。避免误拖。
- 实施位置（项目详情「实施位置」弹窗、编辑计划方案「位置信息」标签、计划方案行内）直接拖动选点。
- **高德配置**：`.env` 的 `VITE_AMAP_KEY` + `VITE_AMAP_SECURITY_CODE`（v2.0 必填安全密钥），且需在高德开放平台配置**域名白名单**（开发加 `localhost`）。配置缺失时地图提示错误码、可手动输入，不影响其它字段。
- 选中的经纬度随保存提交（period 实体 `longitude` / `latitude`）。

## 五、项目状态流转（合同签订 → 审批通过 → 筹备中）

- 未开始(NOT_STARTED) → 列表「合同签订」按钮 → 填写合同信息提交（`status=1` 待审批，弹窗锁定只读）
- 有审批权限角色再点「合同签订」→ 审批：**通过 → `status=2` + 项目流转「筹备中」**；**驳回 → `status=0` + 填写审批原因**，发起人可修改重提
- 详情页不显示「合同签订」按钮（入口只在项目管理列表）

## 六、合同按钮权限配置（审批权限在哪配）

前端通过权限码控制「合同签订」按钮显示与「合同审批」操作：

| 权限码 | 作用 | 给谁 |
| --- | --- | --- |
| `project:contract` | 显示「合同签订」按钮（可提交/查看） | 项目发起人/普通用户 |
| `project:contract:audit` | 审批模式下显示「通 过 / 驳 回」按钮 | 指定审批角色 |

**正式后端配置步骤**：
1. 系统管理 → **菜单管理** → 找到「项目管理」菜单 → 「新增」按钮权限：
   - 菜单名称：合同签订；**权限标识（按钮编码）：`project:contract`**；菜单类型：按钮
   - 菜单名称：合同审批；**权限标识（按钮编码）：`project:contract:audit`**；菜单类型：按钮
2. 系统管理 → **角色管理** → 选择角色 → **授权** → 勾选对应按钮权限（发起人角色勾 `project:contract`，审批角色再勾 `project:contract:audit`）。
3. 用户重新登录后生效（前端 `hasPermission` 从登录返回权限码判断）。

**前端 mock**：`mock/sys/menu.ts` 的 `codeList` 已包含这两个权限码，`pnpm dev`（mock）可直接演示。
