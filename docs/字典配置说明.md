# 字典配置说明（类型/状态下拉统一走字典）

> 更新：2026-08-18
> 原则：**所有「类型 / 状态 / 属性」类下拉一律走「系统管理 → 数据字典」**，前端**不再硬编码选项**（已移除兜底列表）。字典未配置 → 下拉为空，需在后台补字典，不再静默回退。
> 加载：登录返回 `sysAllDictItems` + 实时 `/sys/dict/getDictItems/{code}`。

## 一、字典编码清单

| 字典编码 | 含义 | 单选/多选 | 使用位置 |
| --- | --- | --- | --- |
| `project_type` | 项目类型 | 单选 | 项目管理-新增/编辑「项目类型」；项目管理/计划方案管理 搜索「项目类型」 |
| `project_business_attr` | 业务属性 | 多选 | 项目管理-新增/编辑「业务属性」 |

| `project_period_status` | 项目分期状态 | 单选 | 项目管理/计划方案管理 列表「项目状态」标签、详情头部状态徽标、搜索「状态」 |
| `contract_type` | 合同类型 | 单选 | 合同签订/审批弹窗「合同类型」、回款管理 搜索/编辑「合同类型」（**项目合同 / 维保合同 / 无合同**） |

## 二、创建步骤

1. 登录后台 → **系统管理 → 数据字典** → 新增字典（字典编码/字典名称填上表的编码与含义）。
2. 进入该字典 → 新增字典项（`value` / `text` / 排序；`project_period_status` / `contract_status` / `outsourcing_status` 还可配颜色色值）。
3. 重新登录或刷新页面，前端即自动加载。

## 三、字典项 value 一致性（重要，务必看）

前端下拉的 **`value` 会随保存提交到后端**，因此字典项的 `value` **必须与后端已存数据一致**：

- **项目相关字典（`project_type` / `project_business_attr` / `project_products`）真实后端存的是编码**（如 `1`、`2`），多选字段存逗号分隔字符串（如 `"2,1"`）。→ 字典 `value` 用编码（`1/2/3...`），`text` 为展示文案。
  - 前端已做「数组 ⇄ 逗号字符串」自动转换：编辑回显时把 `"2,1"` 拆成 `["2","1"]`，保存时 `["2","1"]` 合回 `"2,1"`（见 `ProjectApply.vue` 的 `loadDetail` / `handleSave`）。
- `project_period_status` 的 `value` 为状态码（`NOT_STARTED / PREPARING / IMPLEMENTING / DEBUG_COMPLETED / IMPLEMENT_COMPLETED / INTERNAL_ACCEPTING / ACCEPTING / WARRANTY / COMPLETED / CLOSED`），与后端 `period.status` 一致。
- `contract_status` 的 `value` 为 `0 / 1 / 2`，与后端 `contract.status` 一致。
- `outsourcing_status` 的 `value` 为 `0 / 1`，与后端 `OaOutsourcingUnit.status` 一致。
- `contract_type`：项目合同 / 维保合同 / 无合同（`value` 建议用中文文本与存量一致）。

> 若字典 `value` 与存量不一致，编辑回显会丢失文案（显示原始 value），属字典配置问题，非代码 bug。

## 四、合同签订 / 审批流程（与 contract_status 联动）

- 提交合同（`/project/contract/add` 或驳回后 `/edit`）→ `status=1` 待审批；销售负责人随单提交 `salesUserId` / `salesUserName`（默认当前登录用户）。
- 审批（`/project/contract/status`）：**通过 → `status=2`** + 项目流转到「筹备中」；**驳回 → `status=0`** + 填 `approvalReason`（审批原因）。
- 项目管理列表「合同状态」列读 `contract_status` 字典展示；后端项目列表接口需返回 `contractStatus`。
- 权限码：发起合同 `project:contract`；审批 `project:contract:audit`（角色授权里配）。
