# 首汇OA 菜单配置傻瓜指南（后台手动操作版）

延期审批待办：两端点击延期待办即可查看详情，不需要新增页面菜单。需要审批的角色应授权 `project:delay:approve` 按钮，并覆盖所用终端（两端共用可选 `ALL`）；审批前同步权限。没有该权限时只能查看。本次没有代为创建或修改正式授权。

> 适用：登录正式后端 → **系统管理 → 菜单管理** 页面，逐条手动录入。每配完一项点「保存」；全部配完后**重新登录**（或清权限缓存）生效。若菜单打开异常，先看文末「常见问题」。

## 〇、操作通用说明（先读这个）

**新增菜单的标准动作**：

1. 在左侧菜单树**点中父菜单**（如「物料管理」），再点右上角 **「新增菜单」**。
2. 弹出表单，按下面的「填表清单」填。
3. 保存。

**填表字段规则**（重点）：

| 表单字段       | 一级菜单              | 子菜单                               | 隐藏路由               | 按钮权限          |
| -------------- | --------------------- | ------------------------------------ | ---------------------- | ----------------- |
| 菜单类型       | 一级菜单              | 子菜单                               | 子菜单                 | 按钮权限          |
| 适用终端       | PC / 移动端 / 两端共用 | 不得超出父菜单终端范围               | 按实际入口选择         | 按按钮使用端选择  |
| 菜单名称       | 模块名                | 页面名                               | 页面名                 | 按钮名            |
| 路径(路由地址) | `/material`（带斜杠） | `/material/list`（**完整绝对路径**） | `/project/detail/:id`  | 空                |
| 组件路径       | `LAYOUT`              | `project/index`                      | `project/detail/index` | 空                |
| 移动端路径     | 按需填 `/pages/...`   | 按需填 `/pages/...`                  | 按需填 `/pages/...`    | 空                |
| 是否路由菜单   | **是**                | **是**                               | **是**                 | —                 |
| 是否隐藏       | 否                    | 否                                   | **是**                 | —                 |
| 权限标识       | 空                    | 空                                   | 空                     | `project:plan` 等 |
| 图标           | 有就填                | 有就填                               | 空                     | 空                |

**几个铁律**：

- ⚠️ 子菜单路径**填完整绝对路径**（`/material/list`），不要只填相对 `list`，否则路由丢失父前缀。
- ⚠️ **「是否路由菜单」开关必须打开**（`route=1`），否则页面打开 404（前端忽略路由构建）。
- ⚠️ 子菜单组件**必须是真实页面路径**（如 `project/index`），**不能是 `LAYOUT`**，否则打开是空白页（显示"查看组件引用是否正确"）。
- 隐藏路由 = 靠列表按钮跳转的页面（如新增项目、项目详情），不显示在侧边栏，但**必须配**，否则按钮跳转 404；领料申请和还料申请属于通用入口，不设为隐藏。
- `PC端` 只维护 PC 路由和组件，`移动端` 只维护 `/pages/...` 移动端路径，`两端共用` 同时维护两套路径。移动端子菜单不能挂在 PC 专用父菜单下。
- `移动端路径` 可填在一级菜单或需要独立 App 入口的子菜单上，必须与 App `pages.json` 完全一致，不带域名和参数；按钮权限不填。App 会递归读取已授权节点并按路径去重。
- 菜单保存后还要进入 **角色管理 → 授权**：PC 权限在“PC端权限”页签勾选，App/小程序权限在“移动端权限”页签勾选，两边互不覆盖。已定义数据规则的菜单节点右侧会显示“配置数据规则”按钮，点击按钮为当前角色、当前端选择规则；点击菜单名称不会再误打开规则弹窗。

- 勾选物料管理父节点及领料申请、还料申请。
- 勾选资源管理父节点及车辆管理、车辆详情。
- 勾选实施管理父节点及实施列表、查看日志、日志详情。
- 项目按钮勾选“实施完成”（`project:implement`）、“外部验收”（`project:accept`）和“申请返工”（`project:rework:apply`）；不要勾选内部验收、合同审批、计划审批、补料审批、返工审批及系统管理权限。

**运维部门经理角色**：勾选主页、项目详情及“内部验收”（`project:internalAccept`）。不要把“内部验收”授予普通项目成员；正式待办和数据范围还必须由后端按运维部门经理身份限制。

“新增/修改/查看报价”隐藏页必须填写固定路径 `/plan/material-draft/editor`，不要填写旧的动态路径 `/plan/material-draft/:id`。新增时页面跳转为 `/plan/material-draft/editor?mode=create&periodId=项目分期ID&candidateName=报价单名称`，修改时传 `mode=edit&periodId=项目分期ID&candidateId=候选清单ID`，查看详情传 `mode=view` 并强制只读，确保后台动态路由能稳定匹配并精确回显一份报价。

当前菜单管理页面没有“当前激活菜单”输入项，不需要填写。前端识别到组件 `plan/material-draft/editor` 后，会自动让侧栏高亮 `/plan/material-draft` 的“报价管理”。

注意层级：“新增/修改/查看报价”与“报价管理”是同级菜单，都直接放在一级“计划方案管理”下面；只有五个按钮权限放在“报价管理”下面。不要把隐藏页放到“报价管理”里面，否则父子路径会再次拼接，新增跳转仍会找不到页面。

在“报价管理”菜单下面依次新增五个按钮权限：`plan:quotation:add`（新增）、`plan:quotation:edit`（修改）、`plan:quotation:lock`（报价审批，旧编码复用）、`plan:quotation:unlock`（旧权限，当前不再显示通用解锁入口）、`plan:quotation:delete`（删除）。报价审批权限只分配给指定审批人；已采用报价只在合同驳回或撤回后由可编辑合同人员解锁。

“查看详情”和“导出”沿用报价管理菜单的查看权限，不需要额外新增按钮权限。

## 八、常见问题（配完后排查）

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 打开某菜单是**空白页**，提示"查看组件引用是否正确" | 子菜单组件路径配成了 `LAYOUT` 或写错 | 编辑该子菜单，组件路径改成真实页面（如 `project/index`） |
| **页面 404，但菜单能显示在侧边栏** | 该菜单「是否路由菜单」开关没开（`route=0`） | 编辑菜单，把「是否路由菜单」打开 |
| 访问路径不对/404 | 子菜单路径只填了相对值（如 `list`） | 改成完整绝对路径（`/material/list`） |
| 列表页按钮不显示（如「合同签订」「计划审批」） | 按钮权限码没配，或角色没授权 | 按上面清单配按钮权限；再给角色授权 |
| 点「编辑/编辑计划方案/合同信息」跳 404 | 对应隐藏路由没配 | 补齐隐藏路由（apply/contract/plan/detail/:id 等） |
| 外协单位打开 404 | 后端菜单路径拼错 `outsourcig` | 改成 `outsourcing` |
| 配置完菜单不显示 | 权限缓存未刷新 | 重新登录，或清浏览器缓存 |
| **配置完（含角色授权后）菜单仍不出现** | **后端菜单权限缓存未刷新**（`getUserPermissionByToken` 返回旧菜单） | **让后端清 Redis 缓存或重启后端服务**，再重新登录 |
