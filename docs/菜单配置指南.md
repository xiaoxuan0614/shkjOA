# 菜单配置指南（后端「菜单管理」）

> 本工程为 JeecgBoot Vue3 前端，权限模式为 **BACK（后端返回菜单）**。 **正式环境的侧边栏菜单、路由全部由后端 `sys_permission` 菜单表驱动**，前端 `src/router/routes/modules/*.ts` 只是 mock/兜底。新功能上线，必须在后台「系统管理 → 菜单管理」里配好菜单，前端才能访问。

> 💡 **需要逐条手把手操作？** 请直接看 [菜单配置傻瓜指南.md](菜单配置傻瓜指南.md)（每个菜单填什么值都写好了）。

### 移动端路径配置

- 一级菜单新增可选字段 `移动端路径（miniAppPath）`，用于 SHKJ App/小程序工作台跳转。
- 路径必须以 `/pages/` 开头，并与移动端 `src/pages.json` 已注册页面完全一致；不要填写域名、query 或 hash。
- 留空表示该一级菜单不在移动端展示。按钮权限节点不填写移动端路径，继续通过 `perms` 授权标识控制操作。
- 修改现有菜单的移动端路径不会改变菜单 ID，原角色授权仍保留；只有新增或拆分菜单节点时才需要重新给角色授权。
- 保存后应退出并重新登录验证 `/sys/permission/getSystemMenuList`；返回旧值时检查后端菜单/Redis 权限缓存。

## 一、配置前必读：component 路径规则

后端菜单里的 `组件路径(component)` 会映射到前端 `src/views/` 目录下的文件（`src/utils/dynamicPages.ts` 的 `import.meta.glob` 注册，支持 `.vue` / `.tsx`）。

| 菜单里的 component 写法      | 对应的前端文件                             |
| ---------------------------- | ------------------------------------------ |
| `project/index`              | `src/views/project/index.vue`              |
| `project/apply/ProjectApply` | `src/views/project/apply/ProjectApply.vue` |
| `project/contract/index`     | `src/views/project/contract/index.vue`     |
| `project/plan/ProjectPlan`   | `src/views/project/plan/ProjectPlan.vue`   |
| `resource/outsourcing/index` | `src/views/resource/outsourcing/index.vue` |
| `todo/index`                 | `src/views/todo/index.vue`                 |

**规则**：不带 `.vue` 后缀；目录层级用 `/` 分隔；`xxx/index` 命中 `src/views/xxx/index.vue`。 **约定**：路径统一**不带前导斜杠**（`resource/outsourcing/index` 而非 `/resource/outsourcing/index`）。

## 三、按钮权限清单（操作按钮显隐）

在「菜单管理」里为对应**子菜单**添加「按钮」类型的权限项，再在「角色管理 → 授权」勾选，前端 `v-auth` / 流转按钮 `auth` 依据权限码放行。

### 3.1 项目管理 `/project/list`

| 按钮名称      | 权限标识                 | 作用                                           |
| ------------- | ------------------------ | ---------------------------------------------- |
| 合同签订      | `project:contract`       | 未开始项目的「合同签订」按钮（跳转合同信息页） |
| 合同审批      | `project:contract:audit` | 合同信息页内审批待审核合同；通过时指定项目经理 |
| 计划审批      | `project:plan:audit`     | 待立项项目查看完整计划详情并执行通过/驳回      |
| 开始/完成实施 | `project:implement`      | 实施中/调试完成 的流转按钮                     |
| 内部验收      | `project:internalAccept` | 验收阶段的内部验收按钮                         |
| 客户验收      | `project:accept`         | 验收阶段的客户验收/进入质保按钮                |
| 质保          | `project:warranty`       | 质保中的项目完结按钮                           |

> 角色授权建议：销售至少给 `project:contract`；合同审批人给 `project:contract:audit`；计划审批人给 `project:plan:audit`。

> 项目列表不再单独显示“合同审批”按钮。合同通过前统一显示“合同信息”，进入页面后仅当 `contractStatus=2` 且拥有 `project:contract:audit` 时显示审批区域。合同通过后列表入口隐藏，只能从项目详情查看。新授权后需重新登录或刷新权限缓存。

### 3.2 合同信息页 `/project/contract`

- 待审核合同默认只读；拥有 `project:contract:audit` 的用户可在页面内通过或驳回。
- 原提交人可撤回待审核合同；待提交、驳回或撤回后可修改并重新提交，按合同 `createBy` 身份控制，不再需要 `project:contract:edit`。

### 3.3 物料管理 `/material/list`

| 按钮名称  | 权限标识                                                         |
| --------- | ---------------------------------------------------------------- |
| 新增      | `mtl:goods:add`                                                  |
| 编辑      | `mtl:goods:edit`                                                 |
| 删除      | `mtl:goods:delete`                                               |
| 批量删除  | `mtl:goods:deleteBatch`                                          |
| 出入库    | `mtl:goods:io`                                                   |
| 导出/导入 | `mtl:materiallist:exportXls` / `mtl:materiallist:importExcel` 等 |

## 四、配置步骤（后台操作）

1. 登录系统，进入 **系统管理 → 菜单管理**。
2. 点「新增」创建**一级菜单**：菜单类型=`一级菜单`，路由地址=`/xxx`，组件路径=`LAYOUT`，保存。
3. 选中该一级菜单，点「新增」创建**子菜单**：菜单类型=`子菜单`，路由地址=**完整绝对路径**（如 `/project/list`），组件路径=`project/index`（不带前导斜杠、不带 .vue），保存。
4. 隐藏路由同样配置，勾选「是否隐藏」。
5. 按钮权限：选中子菜单 → 新增「按钮」类型 → 权限标识填上表编码。
6. 角色管理 → 授权 → 给角色勾选对应按钮权限。
7. **重新登录**（或清权限缓存）生效；若后端菜单有缓存，需后端清 Redis / 重启。

> 若「菜单管理」里 `菜单类型` 支持 `按钮`，为操作按钮加权限标识配合前端 `v-auth` 使用。

## 六、常见排查

| 现象                                               | 原因                                 | 解决                                       |
| -------------------------------------------------- | ------------------------------------ | ------------------------------------------ |
| 打开某菜单是**空白页**，提示"查看组件引用是否正确" | 子菜单组件路径配成了 `LAYOUT` 或写错 | 组件路径改成真实页面（如 `project/index`） |
| **页面 404，但菜单能显示**                         | 「是否路由菜单」没开（`route=0`）    | 打开「是否路由菜单」                       |
| 访问路径不对/404                                   | 子菜单路径只填了相对值               | 改成完整绝对路径（`/project/list`）        |
| 列表按钮不显示（合同签订/计划审批等）              | 按钮权限码没配 / 角色没授权          | 按第三节配按钮权限 + 角色授权              |
| 点「编辑/新增/合同信息」跳 404                     | 对应隐藏路由没配                     | 补齐隐藏路由                               |
| 外协单位 404                                       | 后端菜单路径拼错 `outsourcig`        | 改成 `outsourcing`                         |
| 配置完菜单不显示                                   | 权限缓存未刷新 / 后端菜单缓存        | 重新登录；后端清 Redis/重启                |
