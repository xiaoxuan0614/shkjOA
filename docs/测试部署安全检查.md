# 测试部署安全检查（2026-09-14）

## 本轮前端加固

- PC 附件预览仅对配置的 API/文件服务域名及路径前缀发送 Token，外部附件不带 Token/Cookie；禁止重定向，防止跨站转发自定义认证头。限制 20 MB、30 秒，切换或关闭取消旧请求，按流限制读取大小。
- 移动端 H5 附件预览同步禁止重定向，保留原有认证域名限制、20 MB 和超时校验；小程序/App 的 `uni.downloadFile` 无通用禁重定向选项，服务端文件接口必须禁止跳转至外域，仍待服务器与真机验证。
- PC 两套登录组件、移动端开发模式取消自动填入 admin/默认密码。正常登录、记住账号、找回密码保留；没有更改真实账号密码。
- 通知详情、消息列表、Markdown 输出经共享 HTML 白名单过滤后展示，不改写数据库原文。此措施不代表所有富文本入口或 Office 渲染库已完成安全审计。
- Vite 移除 `allowedHosts: true`，恢复默认 Host 校验；保留 LAN 调试。不得对公网发布开发服务。
- Rollup 定向升级至 4.59.0，nanoid 3.x 的受影响版本约束为 3.3.19，使用 pnpm 锁文件安装。

## 上线前仍需处理（服务端及待决项）

1. 后端禁用匿名注册接口；隐藏注册按钮不能阻止直接请求。校验每个业务接口的身份、角色、部门/项目数据范围，不信任前端传来的身份和审批资格。
2. 管理员检查默认/弱口令，必要时重置并撤销旧会话；登录限流、错误次数限制、验证码、密码重置接口限流在后端完成。
3. TinyMCE 6.6.2 及旧适配器仍有已知漏洞。修复版涉及授权选择，未擅自升级到 GPL/商业授权版本；HTML 展示过滤不能替代编辑器升级。MockJS npm 当前发布版仍为 1.1.0，未伪造不存在的修复版本；production 已关闭 Mock，但依赖告警仍需跟进。
4. Nginx/API 配置 HTTPS、严格 CORS 来源、响应安全头、上传类型/大小/内容校验及文件读取鉴权；附件服务禁止对外域重定向。测试系统限制访问来源或 VPN，勿直接对公网开放。
5. 前端构建变量不能保存秘密；地图安全配置需评估服务端代理及凭据轮换。通用 HTTP 拦截器、其他 HTML/Office 渲染入口尚需专项核查。
6. 两端通过真实账号回归登录、附件打开/关闭/切换、富文本及权限隔离后再发布；构建通过不代表后端安全验收。未在本轮部署或修改服务器、真实账号及角色。
