## 四、对接要点 / 待确认

1. **状态码**：字典编码 `project_period_status`；状态流转改统一接口 `POST /project/period/changeStatus`(前端传 `{ periodId, targetStatus }`)，新增 `PREPARING(筹备中)` 状态（未开始 → 合同签订+确认 → 筹备中 → 实施中）。⚠️ 统一接口后端待提供；targetStatus 与字典编码需对齐。
2. **验收报告文件ID**：`reportFileId`/`completionReportFileId`/`acceptanceFormFileId`/`planFileId`/`attachmentFileId`/`fileId` 目前前端用 `/sys/common/upload` 上传后存返回路径，**fileId 字段语义(存 id 还是 url)需与后端确认**。
3. **删除主项目**：后端仅提供删除分期，主项目删除/批量删除未接入。
4. **回款计划**：后端无回款计划实体；合同已含 `receivedAmount`(已回款)，未回款=合同金额-已回款前端计算。
5. **standalone 计划/实施/回款模块**：列表已对齐后端，详情页(方案详情/日志详情/合同回款)为设计稿结构，后续按后端实体重构。
