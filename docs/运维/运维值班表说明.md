# 运维值班表说明

## 1. 页面入口

- PC 路由：`/operation/list`
- 前端组件：`operation/duty-roster/index`
- 所属一级菜单：运维管理

正式后台已配置“运维管理”一级菜单和“运维值班表”显示子菜单，访问路径为 `/operation/list`，组件为 `operation/duty-roster/index`，并已为管理员角色授权。静态路由和 Mock 菜单保持一致；其他角色需要使用时仍应单独勾选这两个菜单权限。

## 2. 排班规则

- 默认同时启用早班和夜班，允许按月份关闭其中一个班次。
- 早班、夜班默认人数分别为 2 人和 1 人，仅用于自动排班；自动生成后，每天的人员数量仍可手动调整。
- 自动排班按所选人员顺序循环，人员足够时优先避免同一人同日兼任早班和夜班；人员不足时允许兼任并给出提示。
- 夜班联系人默认取当天第一位夜班人员，也可以在当天夜班人员中重新指定。
- 联系电话读取系统用户手机号；用户未维护手机号时页面显示提示，Excel 对应单元格留空。

## 3. 数据边界

2026-09-01 刷新的 Apifox 项目 8679942 尚无值班表查询、保存或导出接口。当前版本不臆造后端路径：

- 系统人员仍通过项目现有的 `/sys/user/list` 用户加载逻辑选择。
- 月度值班表以 `shkj:duty-roster:YYYY-MM` 为键保存到当前浏览器 `localStorage`。
- 本地保存不能跨浏览器、跨设备或跨账号共享；清除浏览器站点数据后会丢失。
- 页面已把本地存储与 Excel 导出拆分成独立文件，后端补充接口后应仅替换数据读写层，保留页面排班交互。

## 4. Excel 输出

- 文件名：`YYYY年M月运维值班表.xlsx`
- 工作表标题：`YYYY年M月 值班表`
- 列：时间、星期、早班、夜班、联系电话。
- 标题和表头使用黄色背景；标题合并单元格，表格带完整边框并按一页宽度设置打印。
- 联系电话只导出当天指定夜班联系人的手机号。

## 5. 后端接口建议

后续需要跨设备共享时，由后端在 Apifox 中确认契约后再接入，至少覆盖：

- 按月份查询值班表。
- 按月份全量保存班次配置和每日明细。
- 服务端校验用户、日期、班次和联系人从属关系。

接口落地前，前端不得预先写死建议路径或把本地保存描述为服务器保存。
