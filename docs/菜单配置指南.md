# 菜单配置指南(后端「菜单管理」)

> 本工程为 JeecgBoot Vue3 前端,权限模式为 **BACK(后端返回菜单)**。
> **正式环境的侧边栏菜单、路由全部由后端 `sys_permission` 菜单表驱动**,前端 `src/router/routes/modules/*.ts` 只是 mock/兜底。
> 新功能上线,必须在后台「系统管理 → 菜单管理」里配好菜单,前端才能访问。

> 💡 **需要逐条手把手操作？** 请直接看 [菜单配置傻瓜指南.md](菜单配置傻瓜指南.md)（每个菜单填什么值都写好了）。

---

## 一、配置前必读:component 路径规则

后端菜单里的 `组件路径(component)` 字段,会映射到前端 `src/views/` 目录下的文件(通过 `src/utils/dynamicPages.ts` 的 `import.meta.glob` 注册,支持 `.vue` / `.tsx`)。

| 菜单里的 component 写法 | 对应的前端文件 |
| --- | --- |
| `project/index` | `src/views/project/index.vue` |
| `project/apply/ProjectApply` | `src/views/project/apply/ProjectApply.vue` |
| `resource/vehicle/index` | `src/views/resource/vehicle/index.vue` |
| `resource/customer/index` | `src/views/resource/customer/index.vue` |
| `resource/supplier/index` | `src/views/resource/supplier/index.vue` |

**规则**:不带 `.vue` 后缀;目录层级用 `/` 分隔;`xxx/index` 会命中 `src/views/xxx/index.vue`。
**约定**:路径请统一**不带前导斜杠**(`resource/customer/index` 而非 `/resource/customer/index`),与现有 mock 菜单一致。

## 三、配置步骤(后台操作)

1. 登录系统,进入 **系统管理 → 菜单管理**。
2. 点「新增」创建**一级菜单**(如「资源管理」):
   - 菜单类型:`一级菜单`
   - 菜单名称:资源管理
   - 路由地址:`/resource`
   - 组件路径:`LAYOUT`
   - 排序:按需
   - 保存。
3. 选中该一级菜单,点「新增」创建**子菜单**(如「车辆管理」):
   - 菜单类型:`子菜单`
   - 菜单名称:车辆管理
   - 路由地址:`vehicle`(**相对路径**,子菜单的路径不需要前导斜杠)
   - 组件路径:`resource/vehicle/index`(**不带前导斜杠、不带 .vue**)
   - 图标、排序按需
   - 保存。
4. 重复第 3 步添加其余子菜单。
5. 配置完成后,**重新登录**(或刷新权限缓存),左侧菜单即出现。

> 若「菜单管理」里某个菜单的 `菜单类型` 支持 `按钮` 类型,可以为操作按钮加权限标识(如 `resource:customer:add`)配合前端 `v-auth` 使用,非必须。

## 四、菜单与前端路由的对应关系速查

| 前端路由文件 | 一级 path | 说明 |
| --- | --- | --- |
| `src/router/routes/modules/material.ts` | `/material` | 物料管理 |
| `src/router/routes/modules/project.ts` | `/project` | 项目管理 |
| `src/router/routes/modules/resource.ts` | `/resource` | 资源管理(车辆管理/往来客户) |

> 前端路由文件仅用于 **mock 模式**(`pnpm mock`)和开发兜底。正式环境(`pnpm dev` 代理真后端)以菜单管理配置为准,前端路由文件无需改动。
> 若正式环境某个菜单没显示或访问 404:优先检查 ① 菜单是否已保存并重新登录;② `组件路径` 是否写对(对照上面第二节表格);③ 前端对应 `src/views/...` 文件是否存在。
