# 字典配置说明（类型/状态下拉统一走字典）

> 更新：2026-08-24。原则：**所有「类型 / 状态 / 属性」类下拉一律走「系统管理 → 数据字典」**，前端**不再硬编码选项**（已移除兜底列表）。字典未配置 → 下拉为空，需在后台补字典，不再静默回退。加载：登录返回 `sysAllDictItems` + 实时 `/sys/dict/getDictItems/{code}`。

| ----------------------- | ------------ | --------- | ------------------------------------------------------------------------------ |

| `contract_type`         | 合同类型     | 单选      | 合同信息页、回款管理 搜索/编辑「合同类型」（**项目合同 / 维保合同 / 无合同**） |

## 二、创建步骤

1. 登录后台 → **系统管理 → 数据字典** → 新增字典（字典编码/字典名称填上表的编码与含义）。
2. 进入该字典 → 新增字典项（`value` / `text` / 排序；`project_period_status` / `outsourcing_status` 还可配颜色色值）。
3. 重新登录或刷新页面，前端即自动加载。

## 三、字典项 value 一致性（重要，务必看）

前端下拉的 **`value` 会随保存提交到后端**，因此字典项的 `value` **必须与后端已存数据一致**：

- **项目相关字典（`project_type` / `project_business_attr` / `project_products`）真实后端存的是编码**（如 `1`、`2`），多选字段存逗号分隔字符串（如 `"2,1"`）。→ 字典 `value` 用编码（`1/2/3...`），`text` 为展示文案。
  - 前端已做「数组 ⇄ 逗号字符串」自动转换：编辑回显时把 `"2,1"` 拆成 `["2","1"]`，保存时 `["2","1"]` 合回 `"2,1"`（见 `ProjectApply.vue` 的 `loadDetail` / `handleSave`）。
- `project_period_status` 的 `value` 为状态码（`NOT_STARTED / PREPARING / IMPLEMENTING / DEBUG_COMPLETED / IMPLEMENT_COMPLETED / INTERNAL_ACCEPTING / ACCEPTING / WARRANTY / COMPLETED / CLOSED`），与后端 `period.status` 一致。
- 合同审批状态不走字典，固定为 `0=驳回`、`1=通过`、`2=待审核`、`3=已撤回`、其他（含空值）`=待提交`，由 `src/utils/approvalStatus.ts` 处理。
- `member_role` 完整字典实时用于参与成员列表回显，避免登录时空缓存遮蔽后台新配置；添加成员弹窗过滤 `0/1/2`，且这三个角色不可删除。人员配置邀请状态固定为 `0=拒绝`、`1=接受`、其他值`=待接受`，不使用 `invite_status` 推断文案。
- `outsourcing_status` 的 `value` 为 `0 / 1`，与后端 `OaOutsourcingUnit.status` 一致。
- `contract_type`：项目合同 / 维保合同 / 无合同（`value` 建议用中文文本与存量一致）。
- `project_material_candidate_status`：状态值必须与候选清单接口一致，配置 `0=草稿`、`1=已提交`、`2=已采用`、`3=已作废`；列表、搜索和编辑页直接按该字典回显。

> 若字典 `value` 与存量不一致，编辑回显会丢失文案（显示原始 value），属字典配置问题，非代码 bug。

## 四、合同签订 / 审批流程（固定状态配置）

- 新增或重新提交合同 → `status=2`（待审核）；销售负责人默认当前登录用户，可修改。
- 合同信息页内选择通过/驳回：**通过 → `status=1`**，选择项目经理并写入合同后将项目流转到「筹备中」；**驳回 → `status=0`** 并填写 `approvalReason`。审批结果为固定选项，不新增字典。
- `status=3` 表示已撤回；其他值（含空值）表示待提交。
- 原提交人可撤回待审核合同；待提交、驳回或已撤回合同可由原提交人修改并重新提交，驳回详情必须展示 `approvalReason`。已通过合同锁定。
- 项目管理列表「合同状态」列使用固定通用转换；后端项目列表接口需返回 `contractStatus`。
- 权限码：发起合同 `project:contract`；审批 `project:contract:audit`（角色授权里配）。
