# 项目全流程需求说明

> 更新：2026-08-18（二版：合同审批移除，审批后移至计划；合同信息页面化）
> 说明：本文档汇总项目从创建到关闭的完整业务流程与需求，作为后续开发/改造的依据。
> 相关文档：[项目模块业务说明](项目/项目模块业务说明.md)、[项目字典配置说明](项目/项目字典配置说明.md)、[字典配置说明](../字典配置说明.md)、[更新记录](../更新记录.md)

---

## 一、角色与职责

| 角色 | 主要职责 |
| --- | --- |
| 销售 | 创建项目基本信息；填写合同信息（页面，提交后只读）；回款节点维护与催款、开票状态；发起/参与关闭项目审批 |
| 项目经理 | 创建计划（邀约参与人员、确认计划用料清单、填写实施计划与位置、验收周期）；提交计划审批（待立项）；「实施完成」进验收 |
| 参与人员 | 接收/接受/拒绝项目邀约；执行实施；填报实施记录 |
| 审批人（部门/总经理） | 计划审批（待立项→立项）、关闭项目审批 |
| 库管 | 依据计划用料清单执行出库 |
| 采购 | 采购管理（与项目合同物料分属两个模块） |
| 总经理 | 关闭项目审批终审 |

---

## 二、项目创建（销售）

1. **销售人员创建项目基本信息**（项目名称、类型、业务属性、涉及产品、甲方、负责人、地址等）→ 项目「未开始」。
2. 销售进入**合同信息页面**（独立页面，非弹窗）：
   - 填写合同信息：合同类型 / 合同编号 / 合同名称 / 合同签订日期 / 计划交付日期 / 合同金额 / 质保期 / 销售负责人（默认当前销售）等；
   - **上传合同附件**；
   - **合同物料清单：只挂文件**——支持**上传文件** 或 **从该项目文件库选择**（按名称搜索）；不解析为明细。
3. **提交后：项目进入「筹备中」；合同信息页面锁定只读**。编辑权限通过权限码隐藏，仅给特定人员开放。

> 注：合同提交**不做审批**（原合同审批已移除），审批后移至「计划创建完成后」。

---

## 三、计划创建（项目经理，项目筹备中）

1. **确认计划用料清单**：
   - 依据合同物料清单**文件**（选择/导入该文件，或手动创建物料，沿用现有物料维护页面）；
   - 在计划内可补充辅料。
2. **选择参与人员 → 发送邀约**：选择人员后发送邀约，**对方接受后才计入参与人员**（可拒绝）；页面**回显已选定的项目经理、销售负责人**。
3. 填写**实施计划、实施位置信息**；实施计划新增**「验收周期」（天）**：从交付到验收完成的预计时间。
4. **提交审批** → 项目状态「**待立项**」。
   - **驳回** → 项目经理可修改计划后重新提交；
   - **审批通过** → 项目可**开始实施**（进入实施中）。
5. 计划审批通过后，生成**计划用料清单**，库管可执行**出库**。

> 说明：原「合同签订+确认」两步流转废弃，改为「合同提交→筹备中→计划审批（待立项）→实施中」。

---

## 四、实施过程（用料管控）

1. 实施过程中申请的用料**必须在计划用料清单内**（计划内）。
2. **计划外物料**需**提报申请 → 审批**；审批通过后**计入计划内**，方可领用。

---

## 五、采购

1. **采购与项目合同物料分为两个模块**（采购管理 与 项目合同物料 独立维护）。
2. 若需一起采购，由**采购人员线下自行沟通**，系统不做关联。
3. 采购需增加字段：**含税金额、未税金额**（二期细化）。

---

## 六、实施完成与验收

1. 实施完成后，由**项目经理点击「实施完成」**进入验收阶段。
2. 验收分**内部验收、客户验收**两条线，**并行执行**；**客户验收通过 → 进入质保期**。

---

## 七、回款

1. **回款节点**：预付款、到货款、验收款、质保金、尾款、全款。
2. **手动录入节点**：维护**节点类型 + 比例**，系统**根据合同金额自动计算**该节点金额。
3. 按项目进行情况触发**催款提醒**给销售负责人。
4. 销售负责人**填写回款记录**，并**填写开票状态**。

---

## 八、外协单位

- 外协单位分为**个人、单位**两种类型（新增 `type` 字段；个人可不填单位开票信息）。

---

## 九、关闭项目审批流程

| 发起人 | 审批链 |
| --- | --- |
| 销售 | 销售 → 总经理 |
| 项目经理 | 项目经理 → 销售 → 总经理 |

> 属例外终态（区别于正常项目完结）。

---

## 十、通知机制

- **站内待办列表**（参与人员邀约、审批提醒、催款提醒）；后续支持**移动端通知**。

---

## 十一、与现有实现对照（开发参考）

| 需求 | 现有代码/模块 | 缺口 |
| --- | --- | --- |
| 项目创建/合同信息 | `project/apply`、`ContractSignModal` | 弹窗→页面化；去掉合同审批；合同物料清单文件 |
| 计划创建/审批 | `project/plan`（六标签） | 邀约机制、验收周期字段、计划提交审批、待立项 |
| 计划用料/出库 | `material/*` | 计划用料清单生成、库管出库 |
| 用料管控 | `material/pick`/`return` | 计划外物料审批 |
| 采购 | `material/purchase` | 拆模块、含税/未税 |
| 验收 | 状态流转 + 验收记录 | 基本具备 |
| 回款 | `payment`、`contractItem` | 节点+比例自动算、催款提醒、开票状态 |
| 外协 | `resource/outsourcing` | 个人/单位类型字段 |
| 关闭项目 | 状态 `CLOSED` | 关闭审批流程 |
| 通知 | — | 站内待办列表、移动端通知 |
