# 物料模块 - 字典配置说明

> 日期：2026-08-13
> **结论：物料模块的字典（业务类型/出入库方向/状态等标签、物料类别下拉）走后端「系统管理 → 数据字典」配置（sys_dict）。前端自动读取，不写死在前端代码。改后台字典 → 重新登录 → 前端生效。**

---

## 一、傻瓜配置步骤（后台配一次）

1. 登录后台 → **系统管理 → 数据字典** → 点「新增」，按下表新建字典。**前 8 个字典已在正式库配置好**；最后 2 个（台账来源 `stock_io_source_type`、台账类型 `stock_io_type`）为本次新增，**当前后端库为空，需手工补录**（见下方第二点底部标注）。
2. 进入每个字典 → 「新增字典项」，录入 **文本 / 值 / 颜色**（颜色可选，填 antd 标签色如 `blue`、`green`，页面标签用它）。
3. **重新登录前端**（或清浏览器缓存后刷新）→ 生效。
4. 之后在后台改某个字典项文本/颜色 → **重新登录** → 前端对应标签跟着变。

> 前 8 个字典**已在正式后端库配置好**（sys_dict），无需再执行任何 SQL；如缺某字典，按上述第 1~3 步在后台「数据字典」页手工补录即可。
> ⚠️ **本次新增 2 个台账字典（`stock_io_source_type`、`stock_io_type`）后端库当前为空**，出入库台账/盘存记录页的「类型/来源」标签需这两个字典才显示中文，请按上表**在后台数据字典页手工补录**（配完重新登录生效）。
> ⚠️ `purchase_order_status` 的**值必须是数字码 0~4**（不是中文），前端已在提交/流转时统一传数字码；若后台把「值」配成了中文，采购状态流转会匹配不到，请修正为数字码。

## 三、前端读取机制（无需改前端）

- **表单下拉**：`JDictSelectTag`（`dictCode: 'stock_apply_biz_type'` 等）→ 自动拉后端字典。
- **列表标签**：`loadDictMap(code)`（`src/views/material/material.util.ts`）→ 先读登录/用户信息接口返回的 `sysAllDictItems`（缓存），没有再实时调 `/sys/dict/getDictItems/{code}`；返回 `{text, color}`，页面 `<a-tag :color>` 渲染。
- 字典项格式：`{ text, value, color }`（与后端一致）。

## 四、为什么之前"配置了不生效"

- 原因：前端之前**写死在前端常量**（`material.dict.ts`），根本没读后台字典 → 后台怎么配都不显示。**已删除该写死文件**，现在全部走后端字典。
- 注意：直接往 `sys_dict` 表插 SQL 的字典，后端有 Redis 缓存，**需要清缓存或重启后端**才进 `sysAllDictItems`；用后台「数据字典」页面新增会自动清缓存。
- 前端缓存来自登录/用户信息接口，所以**配置后需重新登录**前端才刷新。
