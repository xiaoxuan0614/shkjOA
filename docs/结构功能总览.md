# 首汇科技管理平台 — 前端结构与功能总览

> 项目基于 JeecgBoot Vue3 前端框架(权限模式 BACK)。本文档汇总当前已完成的功能模块、代码结构与「功能 ↔ 页面」对应关系。

---

## 一、整体架构与代码组织

每个业务模块都遵循统一的目录结构:

```
src/views/<module>/
├── index.vue            # 列表页(路由入口)
├── <Module>.api.ts      # 接口定义(defHttp 封装)
├── <Module>.data.ts     # 列定义/搜索表单/常量字典
├── <Module>Modal.vue    # 新增/编辑弹窗(如无则省)
├── detail/              # 详情页(多 tab 时)
│   └── index.vue
└── components/          # 子组件(tab 内容 / 抽屉 / 通用组件)
```

配套三件套:
- **静态路由**: `src/router/routes/modules/<module>.ts`(mock/兜底,自动注册)
- **mock 接口**: `mock/demo/<module>.ts`(`pnpm mock` 模式生效)
- **mock 菜单**: `mock/sys/menu.ts`(侧边栏菜单, BACK 模式下由后端返回,此处仅 mock)

> 正式环境菜单走后端 `sys_permission` 菜单表,配置见 [docs/菜单配置指南.md](菜单配置指南.md)。

## 三、各模块功能详解(功能 ↔ 页面)

### 1. 项目管理 `/project`

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 项目列表 | `/project/list` | 项目ID/名称/**主项目名称(分期)**/类型/甲方/负责人/状态/签订日期;搜索;**分期**:主项目 + 期项目平铺;**状态推进按钮**(按当前状态显示下一步操作) |
| 新增项目 | `/project/apply`(隐藏) | 表单:**所属主项目**(选已有主项目则本记录为期,不选则本记录为主项目)+ 主项目名称 + 项目信息;**创建完成后主项目名称/项目名称禁用不可改** |
| 新增计划方案 | `/project/plan`(隐藏) | 六标签:基本信息/用料/人员/实施/位置/回款(编辑态) |
| 项目详情 | `/project/detail/:id`(隐藏) | 8-tab:基本信息/计划方案/项目成员/实施位置/实施记录(查看日志)/**验收记录(含内部验收:上传照片+填写内部验收负责人)**/项目文件/用料清单 + 右侧项目动态时间线 + 头部状态推进按钮 |

**分期设计**:`parentId` + `mainProjectName` 冗余字段;`parentId=0` 为主项目,否则为某主项目下的期项目。

**生命周期状态流转(状态机 + 外部按钮 + 角色顺序权限)**:
`创建(未开始) → 计划(筹备) → 实施开始(实施中) → 实施完成 → 内部验收 → 客户验收 → 质保中 → 质保结束(完结)`；`关闭` 为例外终态。
- **外部按钮操作**:每个状态对应一个「推进到下一状态」按钮(列表操作列 + 详情头部),点击调 `POST /project/status/advance`,**不能跳步/回退**(mock 顺序校验)。
- **角色顺序权限**:每步推进按钮带权限码,前端 `v-auth`/action `auth` 按权限码显示,在 mock 的 codeList 注入放行:

| 步骤 | 推进按钮 | 权限码 |
| --- | --- | --- |
| 未开始→筹备 | 开始计划 | `project:plan` |
| 筹备→实施中 | 开始实施 | `project:implement` |
| 实施中→实施完成 | 完成实施 | `project:implement` |
| 实施完成→内部验收 | 提交内部验收 | `project:internalAccept` |
| 内部验收→客户验收 | 提交客户验收 | `project:accept` |
| 客户验收→质保中 | 确认验收 | `project:accept` |
| 质保中→完结 | 质保结束 | `project:warranty` |

### 2. 计划方案管理 `/plan`(墨刀原型)

| --- | --- | --- |

### 3. 实施管理 `/implement`(墨刀原型)

| 页面 | 路由 | 功能 |

| 工序列表 | `/implement/list` | 项目名称/工序名称/负责人/计划起止/工时/**剩余工期**/状态(未开始·进行中·已延期·已完成);搜索;操作「查看日志」 |

### 5. 资源管理 `/resource`

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 车辆管理 | `/resource/vehicle` | 车牌号/负责人/状态/最近使用·加油·保养时间;新增车辆/编辑/删除 |
| 车辆详情 | `/resource/vehicle/detail/:id`(隐藏) | 3-tab:**使用记录**/**加油记录**/**保养记录**(分页表格+搜索+记录详情弹窗含照片) |
| 往来客户 | `/resource/customer` | 客户名称/联系人/电话/**负责人(销售/维保/客户经理,用户选择器模糊搜索)**/**开票(抬头/税号/银行/账号/地址/电话)**;客户编号**后端生成(新增时留空,保存后自动带出)**;新增/编辑/详情/删除 |

### 6. 物料管理 `/material`

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 物料基本维护 | `/material/list` | 物料**基础信息**维护:编码(**后端生成**)/名称/类别/品牌(**字典 material_brand**)/**型号(规格,必填)**/基准单位/基准单价/安全库存;新增/编辑弹窗内嵌**单位子表**(第一个单位即基准单位);删除/详情;**导入**(importExcel)+**下载模板**(importTemplate);库存数量列**纯数字显示** |
| 库存管理 | `/material/stock` | 所有在库物料**数量**维护:库存/安全库存/库存金额(以基准单位为准);「出入库」手动调整 + **盘存**(调整在库数量,留痕:盘点前后/差异);库存数量列纯数字显示 |
| 出入库管理 | `/material/record` | 领料/还料/采购**申请记录** + **搜索(申请单号/业务类型/审批状态/关联单号=分期号/项目名称)** + 库管**审批** + **逐条/批量出库·入库** + 出入库台账;列含 关联单号/项目名称;**明细抽屉含审批动态(审批人/节点/结果)**;**申请人**可对自己的申请**撤回**(待审批,未出库前,状态置WITHDRAWN已撤回)/**删除**(未审批/已驳回/已撤回)/**修改后重新提交**(已撤回/已驳回);工具栏「领料申请」「还料申请」按钮进入对应申请页 |
| 领料申请 | `/material/pick`(隐藏) | 项目联动(单号↔名称)+使用人/部门默认当前人(登录接口带出)+选物料(看库存)+数量/单位+备注+提交(出库申请);提交成功自动返回列表;撤回/驳回后可编辑重新提交(applyId 回填) |
| 还料申请 | `/material/return`(隐藏) | 项目联动+自动带出**可还料列表**(后端算)+改数量(前端拦超量)+还料人+提交(入库申请);提交成功自动返回列表;撤回/驳回后可编辑重新提交 |
| 采购入库 | `/material/purchase` | **采购订单**(独立模块 `/project/purchaseOrder`):新增(供应商/项目分期/下单日期/明细)+**状态流转**(待采购→采购中→已到货→已入库)+**periodName 列表解析**+**待采购可修改**+**未入库(待采购/采购中/已到货)可关闭填原因(状态置已关闭)** |
| 物料申请 | `/material/apply`(隐藏) | 出入库申请表单(兼容旧入口) |

## 五、快速上手

```bash
pnpm install          # 装依赖(pnpm)
pnpm mock             # mock 模式, 端口 3100, 侧边栏菜单/接口全部走 mock
pnpm dev              # 正式模式, 代理到后端
```

验收入口:
- 计划方案管理:`/plan/list` → 查看方案 → 5 tab
- 实施管理:`/implement/list` → 查看日志 → 详情(找「已延期」行看延期原因)
- 回款管理:`/payment/list` → 详情 → 添加回款;新增合同看回款计划编辑
- 物料管理:`/material/list` → 新增物料(编码自动生成 + 单位子表) → 库存管理(`/material/stock`)行「出入库」手动入库 → 出入库记录(`/material/record`)申请出入库/台账/审批
- 项目管理:`/project/list` → 列表操作列「开始计划/开始实施/…」逐步推进状态 → 详情头部同步推进 → 验收记录 tab 内部验收上传照片
