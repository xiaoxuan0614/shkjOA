# 值班表自定义规则

2026-10-30：PC值班表结构化配置，规则直接进入排班检查，不再解析自然语言。

## 分步导航

依次为：①人员与顺序；②日常人数与休息；③特殊日期与核对；④排班调整与保存。每次只显示当前步骤内容，切换保留数据。已有排班直接进入④；需要重新生成可返回设置，单纯返回不会改写已有明细。未生成不能进入④；保存锁定后只展示结果，解锁修改后可返回配置。

## 页面及优先级

- 工作日/周末白夜班人数可填0至100整数。
- 可启用法定节假日与调休识别，假日沿用周末或单独填人数；未知年份阻止生成，不猜测日历。
- 特殊日期可选当前月单日/范围，独立设置人数。指定日期 > 法定假日/调休 > 自然星期；重叠例外拒绝，休息约束始终生效。
- 夜班后可选不休息、次日上午休息、次日全天休息。全天休息禁止次日白夜班；上午不补人时，休息人若在次日白班，计入名额、下午返岗；补足上午时，先安排足额其他人员，再将昨夜夜班人员列入下午返岗，因此白班总名单可能大于设定人数（当天白班为0不追加）。补班人员在现有班次模型内作为白班人员，不表示其仅上上午班。
- 同日白夜班允许同一人或必须不同人，候选不足报告具体日期，不减少人数或返回半份结果。
- 顺序支持前移/后移，本月接上月末最后夜班人员的下一位，或指定起排人员。指定起排不豁免跨月休息；跳过不可用人员。全员白班不消耗轮次，其余白班先取人，夜班接排。
- 检查成功并核对后生成；规则/顺序改变使旧检查失效。生成后逐日人工修改，保存不按生成规则卡人数。

## 存储边界（需要后端配合）

已刷新Apifox核对queryByMonth/save。当前仅存储日期、白班/夜班/休息人员，不存生成规则、夜班后休息策略、半天班次。此次未自创字段提交，不改接口。

当前规则仅本次编辑有效；重新打开不能回显配置。历史记录上午休息列标记“未记录休息规则”，避免把不休息误算为半天休息；本次生成按已应用策略展示，调整配置但未重新生成不会改变既有表格标记。服务器导出仍采用现有契约，不宣称包含新增策略。

后端后续需支持主表generationConfig（人数、休息模式、补班、白夜班重叠、假日日历策略、指定日期、起排方式）以及每日半天班次/休息明细；查询和导出应一起回显这些快照。现有全天休息人员及白夜班人员仍照常保存。
