# 外协单位 说明

> 更新：2026-08-18
> 页面：`src/views/resource/outsourcing/`（仿供应商管理）
> 路由：`/resource/outsourcing`（资源管理菜单下，菜单标题「外协单位」）
> 接口：apifox 已收录 `/project/outsourcingUnit/*`

## 一、用途

外协单位（外包单位）主数据维护，含开票信息；供项目计划「人员配置」标签的外协单位下拉、实施记录（外协单位/人数/工时）等使用。

## 二、接口（已对齐 apifox OaOutsourcingUnit）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/project/outsourcingUnit/list` | 分页列表（query: `unitCode`/`unitName`/`status`/`pageNo`/`pageSize`） |
| POST | `/project/outsourcingUnit/add` | 新增（`unitCode` 自动生成，如 `WX0001`） |
| POST | `/project/outsourcingUnit/edit` | 编辑 |
| GET | `/project/outsourcingUnit/queryById` | 详情（query: `id`） |
| DELETE | `/project/outsourcingUnit/delete` | 删除单个（query: `id`） |
| DELETE | `/project/outsourcingUnit/deleteBatch` | 批量删除（query: `ids`，逗号分隔字符串） |

## 三、字段

| 字段 | 含义 | 必填 |
| --- | --- | --- |
| `unitCode` | 外协单位编号（自动生成 WX0001，编辑只读） | — |
| `unitName` | 外协单位名称 | 是 |
| `contactPerson` | 联系人 | 否 |
| `contactPhone` | 联系电话 | 否 |
| `address` | 地址 | 否 |
| `status` | 状态：0 启用 / 1 停用（**字典 `outsourcing_status`**） | 否 |
| `invoiceTitle` | 开票抬头 | 否 |
| `invoiceTaxNo` | 税号 | 否 |
| `invoiceBank` | 开户银行 | 否 |
| `invoiceAccount` | 银行账号 | 否 |
| `invoiceAddress` | 开票地址 | 否 |
| `invoicePhone` | 开票电话 | 否 |
| `remark` | 备注 | 否 |
| `id` | 主键(编辑回显) | — |

## 四、字典

- `outsourcing_status`：外协单位状态（0 启用 / 1 停用）。列表「状态」Tag 与搜索/表单下拉均取该字典。

## 五、mock / 正式环境说明

- **mock 模式**：接口由 `mock/demo/outsourcing.ts` 提供样例数据（含 `unitCode`/`status`/开票字段），字典由 `mock/demo/dict.ts` 提供 `outsourcing_status`。
- **正式环境**（对接后端）：需后端①按上表建表并提供接口；②在系统管理→数据字典 建 `outsourcing_status`；③在「菜单管理」补录「外协单位」菜单（组件路径 `resource/outsourcing/index`，见 [菜单配置指南](../菜单配置指南.md)）。**⚠️ 后端菜单路径需为 `/resource/outsourcing`（注意拼写，勿写成 outsourcig），否则页面 404。**
