# 维修内协一级审批结果复用

配置说明：在“复用一级审批结果”和“审批人去重规则”标题旁增加问号提示，支持悬停、键盘聚焦和点击，分别说明维修内协按部门复用与通用节点去重的区别。本次仅增加说明，不改变配置值、接口或权限。

接口依据：Apifox 8679942，2026-10-23 刷新。

- 配置入口：维修内协邀请 → 更多配置 → 其他配置 → 复用一级审批结果。
- 字段：definition.settings.reuseFirstLevelApprovalResult；省略、null、false 均显示关闭，仅 true 开启。不在读取或保存时自动启用。
- 仅维修内协 repair_ops_collaboration 显示开关，普通审批去重规则保持 EVERY_NODE；其他流程不能开启该复用字段。
- 保存设计草稿、完整模型及发布继续使用原接口和修订号，保留其他 settings；用户发布启用新版本后才影响新申请。
- PC审批进程及移动端部门邀请/审批详情按 automatic=true 且 approvalSource=FIRST_LEVEL_REUSE 展示复用标记、实际审批人、时间、原因和来源任务。没有明确复用标记的旧记录不推断为复用。
- APPROVAL_REUSED 历史动作显示“已通过（复用一级审批结果）”。前端不创建自动审批请求、不改任务权限、不自动入组；人员指定仍走原接口。

验证：开关默认/开启/关闭及其他配置保留、模型请求携带字段、旧记录兼容、审批人回显、现有内协审批指派回归。未修改服务器模型，未进行真实账号的新版本发布及审批执行验证。
