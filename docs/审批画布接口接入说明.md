# 审批画布接口接入（2026-10-23）

依据 Apifox 项目 8679942 当日刷新文档。

- 初始化读取 `/workflow/designer/capabilities` 与 `/workflow/model/businessTypes`，业务字段使用服务端目录。
- 新建时选择“维修内协邀请”，调用 `GET /repair/workflow/template`，传 `type=COLLABORATION&personType=INTERNAL`，不传旧版 roleId。不在前端虚构运维主管角色。
- 关联部门主管节点双向转换为 `RELATED_DEPARTMENT_HEADS`，保留 sourceKind、fieldKey、itemIdPath、departmentMode、headMode、emptyPolicy。
- 维修内协固定全部部门通过、同部门任一主管通过、无主管失败。实际成员指派仍是审批结束后的独立业务动作。
- 保存设计草稿走 `/workflow/designer/save`；保存完整定义走 `/workflow/model/save`；用户确认发布后走 `/workflow/model/publish`。设计草稿与模型各用自己的 revision。
- 能力接口未声明支持时阻止关联规则提交；已有普通审批规则不受影响。
- 独立内协 Mock 继续保留，演示数据不作为正式业务模板来源。

验证：workflow-regression、workflow-related-department-regression、workflow-department-mock-regression、workflow-canvas-groups-regression 均通过。Vite 构建通过。浏览器当前会话访问审批配置地址返回404，尚未验证服务器实际保存、发布和审批执行。本次未修改线上模型。
