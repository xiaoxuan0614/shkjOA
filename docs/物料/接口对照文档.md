## 当前项目用料统计与单张执行契约（2026-09-08，覆盖下方历史记录）

- 项目详情“用料统计”使用 `GET /project/materialAccount/page`，必传分期 `periodId`，可传 `keyword/pageNo/pageSize`；响应按 `{records,total,size,current,pages}` 做 20/50/100 服务端分页。核心列展示 `plannedQty/outboundQty/consumedQty/remainingReturnQty/actualCost`，展开行展示申请占用、归还处置、库存和金额字段，所有数量使用 `baseUnitName`。计划用料 `/project/materialPlan/list` 仍保留给补料预览与计划关联。
- 单张办理弹窗从 `GET /stock/apply/items` 逐页读取并按明细 `id` 去重，明细剩余量为 `(approvedQty ?? applyQty ?? unitQty) - executedQty`。出库采用每种物料两行的紧凑布局：信息行的“申请量”读取 `applyQty ?? unitQty`，同时展示 `currentUnitStockQty`、`executedQty` 和剩余待出；操作行填写 `executeQty/remark`。`currentUnitStockQty` 是所选单位实时库存并作为前端上限；接口未返回该值时不按 0 处理，由后端继续做最终校验。
- `POST /stock/apply/execute` 只提交 `{applyId,items}`，每项为 `{itemId,executeQty,remark?}`。固定 `applyType=IN + bizType=RETURN + usageType=PROJECT` 的项目还料每项还必须带 `dispositionType=RESTOCK|SCRAP|LOST`；`SCRAP/LOST` 同时要求 `dispositionRemark`。下方历史记录中“不提交 remark/disposition”或重复传 `itemIds` 的说明不再代表当前实现。
