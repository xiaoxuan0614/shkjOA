# 车辆维护业务与接口

2026-09-13 对照刷新后的 Apifox 项目 8679942。页面目录 `src/views/resource/vehicle/`，列表路由 `/resource/vehicle`，详情 `/resource/vehicle/detail/:id`（路由 id 的值为 vehicleId）。菜单与角色授权未调整。

## 车辆档案

- GET `/vehicle/list`：`pageNo/pageSize/plateNumber/principal/status`，服务端分页 `records/total`。
- GET `/vehicle/queryById`：必传 `vehicleId`，编辑先查询最新详情。
- POST `/vehicle/add`、`/vehicle/edit`：JSON `plateNumber/principal/driveMode/currentMileage`；编辑另传 `vehicleId`。未提供的可选模式、里程不强制用零覆盖。
- DELETE `/vehicle/delete`：query `vehicleId`，操作前确认。没有批量删除契约，移除旧无效入口。
- 负责人是姓名字符串，不是用户 ID；移除演示人员选项。模式 `GPS/OWNER`，里程非负。状态 `空闲/使用中/保养中` 由服务端业务维护，不随档案编辑提交。
- 最近时间为 `latestUseTime/latestRefuelTime/latestMaintainTime`，不回传保存。

## 记录查询

| 类型 | 分页 / 详情接口 | 主键 | 日期查询前缀 |
| --- | --- | --- | --- |
| 行车 | `/vehicle/drive/list`、`/vehicle/drive/queryById` | driveId | driveStartTime |
| 加油 | `/vehicle/refuel/list`、`/vehicle/refuel/queryById` | refuelId | refuelTime |
| 保养 | `/vehicle/maintain/list`、`/vehicle/maintain/queryById` | maintainId | maintainDate |

分页必须携带当前 vehicleId，使用 pageNo/pageSize，日期区间使用 `_begin/_end`，包含选定结束日。详情按记录主键重新查询，不以列表快照代替。

行车字段：useReason/driver/driveStartTime/driveEndTime/driveDuration/mileage/destination/photoUrls。
加油字段：driver/refuelLiter/amount/payType/refuelAddress/refuelTime/photoUrls。
保养字段：submitter/maintainDate/nextMaintainDate/price/remark/maintainAddress。

记录仅查询，移除“删除成功（演示）”占位逻辑；本次未新增行车启动结束、加油录入、维保录入或 GPS 功能。加载失败由共享请求层提示，可重新筛选/查询；旧响应不会覆盖切换后车辆或分页结果。
