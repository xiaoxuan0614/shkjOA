## 接口与状态

- 列表与未读数：GET /sys/sysAnnouncementSend/getMyAnnouncementSend。列表传 pageNo/pageSize、可选 readFlag=0、titile；角标单独传 readFlag=0/pageSize=1，使用 total，避免旧计数接口的月份及分类限制。
- 详情：GET /sys/sysAnnouncementSend/getOne，sendId 使用本人列表 records.id。result=null 显示不可查看，不标记已读。
- 单条已读：详情加载后 PUT /sys/sysAnnouncementSend/editByAnntIdAndUserId，JSON body 为 { anntId }；使用通知主表 ID，不混用 sendId。失败保留正文并可重试；成功回查列表/角标，不直接假设减一。
- 全部已读：确认后 PUT /sys/sysAnnouncementSend/readAll，无请求体，作用于账号全部通知而非当前筛选。
- 通知 API 单独按 success 解包，兼容 code=0/200；不修改全局响应规则。
- WebSocket topic/user、打开抽屉、页面重新获得焦点触发刷新；卸载清除事件监听和计时器。并发列表与详情请求只接受最新响应。
- 正文使用 sanitizeHtml，摘要作为普通文字。未知业务及任意组件路径不执行。
